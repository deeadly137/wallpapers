# Contributing

Anyone can contribute, but here's how you do it:

1. Fork the repo

2. Add wallpapers to `Wallpapers/`
 - Desktop ones go under `Wallpapers/Desktop/<category>/`, phone ones under `Wallpapers/Mobile/`

4. Name your files in lowercase kebab-case, e.g. `my-cool-wallpaper.png` (you can put the resolution at the end, like `my-cool-wallpaper-4k.png`)

5. Commit your changes

6. Create a new pull request on main branch

And then, repository maintainers are going to check if they match the wanted criterion.

> [!NOTE]
> You don't have to touch the preview pages by hand — they are generated by `scripts/generate_previews.py` and CI keeps them up to date.
