# Contributing

Anyone can contribute, but here's how you do it:

1. Fork the repo

2. Add wallpapers to `Wallpapers/`
 - Desktop ones go under `Wallpapers/Desktop/<category>/`, phone ones under `Wallpapers/Mobile/`, animated ones under `Wallpapers/Animated/`

4. Name your files in lowercase kebab-case, e.g. `my-cool-wallpaper.png` (you can put the resolution at the end, like `my-cool-wallpaper-4k.png`)

5. Commit your changes

6. Create a new pull request on main branch

And then, repository maintainers are going to check if they match the wanted criterion:

- PNG or JPEG (JPEG preferred for photos, PNG for flat/gradient art)
- Animated wallpapers are welcome too — mp4 or webm under `Wallpapers/Animated/`
- Files over 10 MB can't be attached to github issues — go through a pull request instead (see below)

## Adding wallpapers without knowing git (web upload)

1. Fork the repo

2. In your fork, open the folder you want (e.g. `Wallpapers/Desktop/Dark/`), then **Add file → Upload files**

3. Commit, then open a pull request against `main`

The browser upload accepts files up to 25 MB each. Anything bigger needs a local clone + git push from your machine, and github hard-rejects files over 100 MB — those need to be re-encoded first.

> [!NOTE]
> You don't have to touch the preview pages by hand — they are generated by `scripts/generate_previews.py` and CI keeps them up to date.
